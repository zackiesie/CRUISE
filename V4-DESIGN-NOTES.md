# CRUISE V4 — Premium Desktop Design Pass

V4 keeps the V3 feature set and focuses on visual consistency and desktop behaviour.

## Visual direction
- Premium automotive/editorial customer experience inspired by the layout principles of Eurokars Leasing: generous whitespace, strong hero surfaces, restrained typography, vehicle-first presentation, and fewer rounded dashboard cards.
- Customer navigation is now a wide top navigation instead of a mobile/app-like permanent sidebar.
- Customer home uses a full-width dark automotive hero, a restrained rental-stat strip, a large next-drive feature, and an editorial three-step journey.
- Fleet cards are larger and wrap naturally as the desktop window changes size.
- Admin remains a dense operations console because its information architecture is different from the customer experience.

## Admin login
The old centered 390px card was removed. Admin login is now a true split-screen desktop composition: branded operations panel on the left and a full-height authentication workspace on the right.

## Desktop consistency
Primary windows use the shared WindowManager policy: resizable, consistent minimum desktop dimensions, and consistent scene sizing. Long pages remain scrollable rather than compressing controls.

## Important
V4 is a visual-system pass. V3 booking, Stripe, Google sign-in, add-ons, returns, maintenance, notifications, reporting and assignment-control functionality are preserved.
